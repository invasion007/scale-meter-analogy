# 杆秤 · 电压表 · 电流表｜同一个"以小测大"的套路

人教版高中物理必修第三册《练习使用多用电表》前置课：用**杆秤**做类比，把「表头怎么变成电压表 / 电流表」讲成同一件事。

在线打开：<https://invasion007.github.io/scale-meter-analogy/>

## 这一课解决什么

1. **杆秤**：砣只有 1 kg（只认识的小量），把长臂 L₂ 拉成 L₁ 的 k 倍，就读出 M = m·k。多的那份"交给"长力臂。
2. **表头**：Ig = 1 mA、Rg = 100 Ω → Ug = 0.1 V。它天生只会喊"满偏了"，只能测 0.1 V / 1 mA。
3. **电压表**：**串联**电阻 Rs，电流处处相同 → 电压按电阻正比分配。表头只留 1/k，剩下的 29/30 全给 Rs → 量程 = 0.1 V × k。
4. **电流表**：**并联**电阻 Rp，两支路电压相同 → 电流按电阻反比分配。表头只走 1/k，其余 599/600 全从 Rp 走 → 量程 = 1 mA × k。
5. **一句话**：三个都是"小量 × 一个比例 = 大量"。杆秤分力矩，电压表分电压，电流表分电流。

## 画面怎么读

| 位置 | 内容 |
|---|---|
| 顶部色条 | 一条 = 总量。红段 = 表头只留的那一小份（1/k），蓝段 = 分走的大份（(k−1)/k） |
| 主图 | 杆秤 / 表头 / 串联电路 / 并联电路（随幕切换） |
| 底部三卡 | 只认识的小量 · 放大倍数 k · 读出来的大量（一屏三数，全部随 k 实时变） |
| 底栏滑杆 | **放大倍数 k**（5× ~ 60×），第 1/3/4/5 幕都能拖 |

## 可拖可换

- 底栏「放大倍数 k」滑杆：k 一变，秤砣位置、Rs/Rp 数值、分压/分流份额、量程、结论卡同步刷新
- 顶部五个数字按钮：任意跳幕（课上"回到第 3 步再说一遍"一步到位）
- 键盘 ← → 翻幕
- 第 2 幕滑杆自动置灰（这一步没有可拖的量，提示语与 allow 白名单严格一致）
